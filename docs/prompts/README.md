# Flutter entegrasyon prompt’ları

Bu klasör üretim/web ile mobil senkron için yüklenen prompt paketidir.

| Dosya | Konu |
|-------|------|
| `FLUTTER_SESLI_SOHBET_PROMPT.md` | Sesli sohbet odası (SSE, müzik, alt menü) |
| `FLUTTER_CANLI_YAYIN_PROMPT.md` | Canlı video yayın |
| `FLUTTER_CANLI_ODA_PROMPT.md` | `/api/live/*` + TRTC |
| `FLUTTER_CANLI_FALCILAR_PROMPT.md` | Canlı falcılar |

**Çelişkide:** [`../FLUTTER_ENTegrasyon_KILAVUZU.md`](../FLUTTER_ENTegrasyon_KILAVUZU.md) geçerlidir.  
API envanteri: [`../FLUTTER_API_DOCS.md`](../FLUTTER_API_DOCS.md), uyumluluk: [`../FLUTTER_BACKEND_UYUMLULUK_RAPORU.md`](../FLUTTER_BACKEND_UYUMLULUK_RAPORU.md).
